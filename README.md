A 4 KB Python chess engine: 0x88 move generation, alpha-beta with a transposition table, null move, late move reductions and a captures-only quiescence, talking UCI moves to the make.fun env.

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python main.py
```
